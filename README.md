# ⚔️ Dungeon Crawler: Gato Roubado

Um jogo de exploração de masmorras (Dungeon Crawler) com visão top-down, desenvolvido inteiramente na linguagem C para ser jogado no terminal utilizando caracteres ASCII. 

---

## 📖 História

Você está de viagem por uma vila nova enquanto o seu gato estava andando pelo parque juntamente contigo. No entanto, quando você virou o olho, ele sumiu!

Em meio a isso, você foi perguntando sobre ele para as pessoas em um bar próximo. Foi nisso que um idoso chegou para você e disse que viu um gato entrando em um velho e mortífero portal. 

De acordo com as lendas, um herói viria para remover a orbe maligna do mago do submundo e salvar a vila. Então, decidido, você foi salvar o seu gato e impedir que o pior aconteça!

---

## 🎮 Como Jogar

O jogo é controlado inteiramente pelo teclado. 

### Controles
* **`w`**: Anda para cima
* **`a`**: Anda para a esquerda
* **`s`**: Anda para baixo
* **`d`**: Anda para a direita
* **`o`**: Ataca (causa dano a inimigos e quebra caixas)
* **`i`**: Interage (conversa com NPC, pega armas, etc.)

### Legenda do Mapa (ASCII)
* `<`, `^`, `>`, `v` - Jogador (apontando para a direção)
* `X`, `Y`, `Z` - Inimigos
* `0` - NPC
* `*` - Parede
* `#` - Espinhos (causa morte)
* `k` - Caixas destrutíveis
* `O` - Botão
* `@` - Chave
* `D` / `=` - Porta fechada / Porta aberta
* `L` - Escada / Portal
